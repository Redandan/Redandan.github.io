# AgoraMarket

This repository retires the legacy Flutter web mirror and redirects visitors
to the current AgoraMarket V2 site. It is not an independent application
runtime.

Browse the current marketplace on the official site:

- [AgoraMarket — Taiwan and Thailand marketplace](https://agoramarket.purrtechllc.com/)
- [Costco Taiwan products](https://agoramarket.purrtechllc.com/products/sources/costco-taiwan)
- [Makro Thailand products](https://agoramarket.purrtechllc.com/products/sources/makro-thailand)

The official site is the canonical source for current products, availability,
and marketplace features. The redirect also unregisters the retired Flutter
service worker so returning visitors do not remain on a cached legacy build.
